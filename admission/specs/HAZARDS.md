# Hazard and probe design v1

H1–H8 are static warnings, never demonstrated bugs. Each warning binds source SHA256/file/line/half-open byte span and rule version. Unresolved pointers yield pointer_unresolved; absent evidence never becomes verified. Every program must have >=2 reachable hazards. Reachability design includes complete valid input rows, execution path and emitted observable affected; actual witness bytes belong to later appointed authors, not this document.

| ID | Conservative trigger | Reachable design obligation | Required probe themes |
|---|---|---|---|
| H1 | arithmetic destination/MOVE loses potential fractional precision without ROUNDED | chosen inputs reach assignment with nonzero discarded fraction, output exposes destination | truncation, tiny discarded fraction, both signs, negative zero MOVE versus arithmetic |
| H2 | arithmetic may exceed destination and no ON SIZE ERROR | inputs reach representable inputs but overflowing result, expose result/declared status | result max/max+ulp, handled versus unhandled, destination preservation on handler |
| H3 | file operation status not checked on every relevant path | explicit missing/empty/EOF/success scenarios reach operation; emit status to observe it | missing input, empty file, successful read, EOF; proposed 35/10 hypotheses only |
| H4 | two-digit-year arithmetic without an explicit pivot guard | today/year input reaches arithmetic across pivot boundary; emit integer result | pivot-1/pivot/pivot+1, both sides; no clock |
| H5 | signed numeric MOVE to unsigned destination | negative/-0 value reaches MOVE and emitted destination | separate sign, signed zero and unsigned receiver behavior |
| H6 | X MOVE has unequal source/destination widths | distinct valid input or fitting literal reaches output assignment | right padding, truncation, empty/all-space and non-space terminal byte |
| H7 | DIVIDE or COMPUTE divisor lacks a dominating nonzero check | zero divisor reaches operation with observed handled/fault outcome | divide zero/nonzero, handler preservation; uncontrolled crash quarantined for oracle |
| H8 | COMPUTE uses >=2 binary operators (maximum3) | values exercise intermediate precision and emitted destination | precedence/parentheses, intermediate size/scale, ties and non-ties |

Dominating guard recognition is structural over all paths; unknown dominance warns conservatively. H1 concerns potential scale loss, not just syntactically unequal PICs. H2 is conservative range analysis. H4 does not assert every two-digit operation is wrong. No branch coverage claim; paragraph/statement coverage only after trace identity and ordinary-output equality checks.

## Probe catalogue to be authored later

Minimum six admission probes, allowing multiple focused assertions per original: A01 signed scale transfer (negative zero included); A02 rounding ties/non-ties both signs; A03 overflow/handler destination preservation; A04 divisor zero and multi-operator intermediates; A05 missing/empty/records/EOF and separate-sign file layout; A06 integer year-pivot sides. These are design labels, not source files, expected bytes or passed tests.

Minimum 24 distinct focused shim probes: S01 positive tie; S02 negative tie; S03 positive non-tie below half; S04 negative non-tie below half; S05 positive non-tie above half; S06 negative non-tie above half; S07 tiny discarded fraction; S08 positive truncation; S09 negative truncation; S10 negative-zero MOVE; S11 negative-zero arithmetic; S12 positive separate sign; S13 negative separate sign; S14 packed internal storage size; S15 packed-to-display truncation; S16 overflow no handler; S17 overflow handler; S18 destination preservation on size error; S19 divide zero; S20 multi-operator intermediate precision; S21 missing-file emitted status; S22 empty/EOF emitted status; S23 pivot lower side; S24 pivot upper side. Add probes when one case cannot discriminate hypotheses. No permission-failure portability claim.

Independently reasoned tiny probe expectations are allowed only to appointed probe authors and labeled instrument sanity hypotheses; general expected outputs exclusively come from repeated compiled originals/changes. Source-plan status values 35/10 and arithmetic descriptions require pinned GnuCOBOL 3.2.0 observations. A failed probe blocks affected semantics/evaluation; never normalize it to the shim. Deterministic compiler/intent disagreement records oracle_dispute and hashes/minimal reproducer/citations without dropping scored cases. Wrong pins, nondeterminism or failed execution are instrument faults.
