# Preparation architecture

The standalone admission generator consumes author-declared field tables and partition recipes without importing product code. Its pure adapter describes case/artifact/index transport. Receipt validation checks supplied consistency; the structural runner refuses execution. The gate binds native manifests, paired recipe indexes and provenance to later actual independently authored evidence; it cannot establish authenticity from hashes.

Canonical shape/hash/semantic contracts live in `admission/specs/`. Actual preparation APIs and capability gaps live beside the source in generator-notes.md, oracle-preparation.md and GATE-NOTES.md. Raw artifact identity, canonical JSON commitments and LF Markdown spec-edition pins remain distinct. Generated candidate counts are not valid oracle admission.

No product package exists before P2 GO. Expected behavior may only come from actual pinned compiled original/changed COBOL under a future authorized isolated backend. Private run/acceptance/deferred records remain in the OUTER shell; no independent role or runtime result is manufactured by this source.
