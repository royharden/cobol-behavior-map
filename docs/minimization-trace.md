# Loop reduction and original trace coverage — source only

Private original P8/P9 construction under the delegated Dirty overlay. No callback/decoder/backend/compiler was invoked, no event/case/witness/receipt/bundle instantiated or authored, and no source was instrumented. Runtime, hard wall isolation, authentic observations/normalization and P2 remain unverified. Imports below describe future caller APIs; no candidate module was imported during construction.

## Loop-only best-found reduction

`from cobolmap.oracle import minimize_loop, LoopContext, ObservationPair`.
`minimize_loop(case, baseline=None, callback=None, *, context=None, max_proposals=100, timeout_seconds=10.0)` returns immutable ReductionResult. Missing baseline/context/bounded callback or untrusted gates returns pending with no calls. Callback is a future externally isolated adapter exposing hard_timeout and evaluate(case, *, timeout_seconds, context); this package supplies none. Context has source bytes/hash, candidate hash, task/program IDs, exact32 original loop hashes, source-bound input/output layouts, separate expected oracle/candidate ExecutionPins, admission/callback ArtifactRefs and default-false admitted/trusted_loop_context/trusted_callback. Booleans/hashes cannot authenticate their own authority; a trusted control plane must supply them after actual admission/capability verification. Verification/held-out inputs are not eligible.

The initial CaseBundle must belong to that original32 and bind exactly to actual original/candidate ordinary observations, expected pins/authority and source/task/candidate/case identity. Shared exact comparator must report mismatch; missing/fixture observations, setup failures, crashes/timeouts or matching uncontrolled faults do not qualify. Every retained proposal requires a fresh actual observation pair for its exact derivative bytes; no copied baseline response can pass a new hash.

Reduction first removes contiguous ordered record chunks while keeping at least one record for record scenarios; then simplifies one valid declared field at a time (numeric zero/sign/fewer digits, alpha spaces). Presence and missing/empty/records scenario stay unchanged. Accepted external DISPLAY codec validates the complete layout and every proposed record; no packed external codec, whitespace/sign/scale normalization or treating batches as sets. Seeded generation, expected-output synthesis and verifier data are absent.

Every retained result preserves original mismatch channels/class/field. Byte-heuristic or unknown classifications also preserve original raw mismatching-channel payloads, return codes or presence distinction. This deliberately conservative criterion can keep a larger witness; it never promotes a heuristic into an established semantic cause. ReductionResult says best_found only for an actual-grounded retained witness, never global minimum/universal validity. Every candidate construction consumes a proposal permit, including duplicate hashes, with <=100 proposals and a separate callback count. Cooperative generation checkpoints and remaining-time checks precede new work/calls within <=10 seconds; the remaining timeout is passed to the adapter. Late responses are not retained and deadline issues remain explicit, including empty/no-proposal cases. Python clock checks cannot interrupt a blocking adapter or an individual local operation: external hard timeout/isolation is mandatory; unsafe or absent capability refuses without dispatch.

Result exposes origin_case_sha256 separately from derivative_case_sha256 (the returned case hash), actual witness, parent/derivative/reason/witness lineage, counts/elapsed/issues. These are LOCAL reduction artifacts, not trusted receipts by themselves. Derivatives never enter the sealed32 or masquerade as original members. Current shared feedback accepts only original32. INT routed a derivative-provenance gap to DL3; until explicit adoption, outbound_feedback_compatible remains false and feedback_payload() refuses. Local lineage stays off wire. Do not serialize the entire result as a model packet or relax membership to make it pass. No shared contract was changed by DL1.

ReductionResult additionally retains origin_case: CaseBundle | None and origin_witness: ObservationPair | None. Each ReductionStep retains parent_case: CaseBundle | None and derivative_case: CaseBundle | None alongside existing hash/reason/witness fields. Fields are appended with None defaults for legacy construction; missing bytes never become reconstructed evidence. The producer stores actual input/baseline and current-best/proposal objects. Local checks validate supplied model structure, case/hash/pair bindings, consistent observation scope/pins/authority/return declarations, contiguous noncyclic lineage capped at100, and final equality with the last retained derivative (or unchanged origin). Value consistency does not authenticate execution or a caller's authority. These fields support a separate local DerivativeEvidence adapter; they activate no verifier, projection or outbound permission. Full baseline/intermediate bytes remain off wire and both compatibility/minimum flags remain hard False.

## Trace inputs and coverage

`coverage(program, records:tuple[TraceCase,...], *, context=None) -> CoverageResult`. Program is original parser IR retaining exact source bytes/hash; coverage uses shared SourcePointer/EvidenceBinding/ExecutionObservation. TraceEvent(kind=paragraph|statement, paragraph, pointer) contains full exact original paragraph/statement identity. TraceCase contains untraced/traced original ExecutionObservations, events tuple, raw_trace bytes, framing ArtifactRef, normalization_receipt ArtifactRef and statement_identity flag. TraceContext binds task/program, the ENTIRE expected scored-case hash scope, exact separate traced/untraced pin sets, actual authority/approved framing, and default-false admitted/trusted_context/trusted_normalized. No generator input is consumed as trace evidence. Mutable/arbitrary iterable records and malformed constructed models refuse rather than invoke a generator or produce partial hits.

All expected cases must be supplied; missing scope/evidence/authority/framing yields pending/not_run with no partial numerator. Untrusted extras, wrong source/hash/pointer/event/kind/paragraph/statement or pin/framing mismatch make coverage invalid. Each observation must be actual, source/task/case bound, original (no candidate pin), completed/handled with declared return and genuine runtime receipt supplied for external authentication. Exact traced/untraced output presence/data/stdout/stderr/return and return declaration must agree per case; matching uncontrolled faults never pass. Repeated case observations must agree, while repeated hits never inflate the union.

Denominators enumerate ALL original paragraphs/statements, including unreachable source, by source syntax (nested bodies included, expressions excluded, no PERFORM expansion). Numerators are unique exact spans/names. If any case lacks reliable statement identity, report paragraph coverage with statement numerator unknown; known statement denominator is retained, no branch metric. Unknown events are rejected rather than inferred as hits.

There is NO known approved GnuCOBOL raw -ftraceall framing receipt or local raw decoder. TraceDecoder is only an external approved protocol decode(raw_trace, *, framing, program)->tuple[TraceEvent,...]; coverage never invokes it, strips stderr, parses guessed raw text or changes original COBOL. Caller must authenticate normalization_receipt content tying raw trace/framing/source/events/statement identity and separate ordinary channels. Locally, raw trace ArtifactRef bytes and exact approved framing/pin identities are checked; receipt presence/hash shape is not authenticity or execution proof. Strict defaults preserve that boundary.

Deferred: actual isolation/remaining-time enforcement and callback lineage; baseline/derivative pin/class/field/raw-criterion cases; ordered ddmin/scenario/codec/proposal-budget/deadline behavior; shared feedback derivative integration; actual compiler trace framing/approved decoder and normalization receipts; source pointer/denominator/unreached/repeated/unknown-event/ordinary-equality cases; full scored-case completeness and genuine P2/admission/independent evidence. Static AST/diff/source review provides construction assurance only; no execution result or acceptance is claimed.
