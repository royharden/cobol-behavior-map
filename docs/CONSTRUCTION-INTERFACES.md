Scope is frozen plan product source under delegated Dirty overlay; no runtime or P2 waiver. Python3.12/Pydantic2 contracts; src layout, evaluation outside distributable wheel. No installs/builds/CI/Docker scaffolding. pyproject is source only; dependency lock/runtime checks deferred.

Ownership: DL1 parse/mapping; DL2 shared decimal/codec and translate; DL3 contracts/diff/claims; DL4 cli/reporting/replay and README. INT owns root packaging, this seam document and integration. Read committed admission specs; source before admission remains disclosed in STUDY-EXPOSURE.md.

DL3 contracts exports SourcePointer with source_sha256, filename, line_start, line_end, byte_start, byte_end (UTF8 source bytes, zero-based half-open byte spans, one-based inclusive lines). Immutable/extra-forbid models bind all source/artifact/observation pins and evidence modes. No source pointer may resolve against different bytes. DL3 publishes the exact models/API first through INT; consumer imports may be provisional until that source lands.

DL1 parse facade: parse(source:str,filename:str="program.cbl")->ProgramIR; ParseRefusal carries stable code/message/span. parse.models owns frozen ProgramIR(source_sha256,filename,fields,paragraphs), FieldLayout(name,pic,usage,sign,offset,width,scale,digits,initial), Paragraph(name,span,statements), IRNode(kind,span,args,body,otherwise). span uses contracts.SourcePointer; args is a closed-by-kind mapping validated by parser, never executable Python. Expressions are literal/reference/binary/compare/boolean nodes. Publish exact per-kind keys early. Refuse partial/unrecognized tokens; no permissive fallback. DL1 mapping facade build_map(program)->BehaviorMap, shared model shape coordinated with DL3. Static hazards are warnings, never execution claims.

DL2 translate facade translate(program,change=None)->TranslationResult(code,original_source_sha256,diagnostics); translator owns its result type. Generated Python is text only, never executed on host. Supported templated edits target one exact source node and refuse missing/ambiguous/hash-mismatched/noop operations. Decimal shim/codec use explicit integer/Decimal context semantics, no floats or eval. Compiler semantics remain hypotheses until actual probes. Build arithmetic/codec independently while reconciling IR kinds with DL1; named seam owner DL1, translator consumer DL2.

DL3 evidence contracts include ProgramManifest/CaseBundle/BehaviorMap/Claim/ExecutionObservation/CandidateAttempt/FeedbackPacket/RunPlan/RunResult from adopted plan, with distinct original/change/raw/canonical identities and no authentic-evidence defaults. Exact comparator consumes real observations; matching uncontrolled crashes do not pass, no normalization/tolerance. Claims use closed DSL/no eval and bounded future oracle interface; no support claim absent actual witnessed observations.

DL4 CLI entry cobolmap.cli:main. Source command paths map/translate/report/demo --mode replay; oracle/live modes must remain explicitly gated, no keys/env/auth reads or assumed approval. Replay only verifies/renders supplied hash-bound evidence and never executes recorded code. Missing authentic replay observations reports unavailable/not_run; do not invent a successful replay bundle. Report HTML escapes all untrusted content, unknown/absent live metrics null/not_run, source hazards unverified. CLI consumers use facades above, named reconciliation DL4 against DL1/DL2/DL3.
