# Bounded parser and static map source

Private original product source constructed before P2 under the delegated Dirty overlay. Runtime unverified; no compiler/semantic parity, admission, independent verification or study result is established. No program/probe/corpus/expected answer is included in this package.

`cobolmap.parse.parse(source, filename="program.cbl", *, manifest=None)` returns frozen `ProgramIR` or raises `ParseRefusal(code, message, span)`. Input is exact decoded source text; callers must preserve CRLF and never normalize bytes before parsing. Accepted source is ASCII, hence UTF8 byte spans equal ASCII byte offsets. SourcePointers use the shared contracts model and bind SHA256, logical relative filename, half-open zero-based byte offsets and inclusive one-based lines. Strings retain decoded values while spans retain original spelling. Comments never become executable tokens.

The tokenizer scans all bytes/tokens, rejects encoding/control/literal errors and enforces 200 physical lines. The parser consumes every token: fixed divisions and input/output SELECT/FDs; 01/05 groups and elementary pictures; DISPLAY/internal COMP-3, separate external sign and representable VALUE; named paragraphs; MOVE/arithmetic/COMPUTE; IF/AND/OR; paragraph PERFORM/UNTIL; OPEN/READ AT END/WRITE/CLOSE/DISPLAY and terminal MAIN STOP RUN. Unknown productions, partial sources, unsupported clauses, mismatched scope, wrong types/layout and unresolved names refuse. COMPUTE has <=3 operators; field/paragraph bounds are enforced. Packed width is a proposed storage layout pending actual pinned compiler probes, never an external packed codec.

`ProgramIR` carries source_sha256, filename, fields, paragraphs, source, files and program_id. All sequence containers are tuples. `IRNode(kind,span,args,body,otherwise)` copies/fixes nested argument containers; arguments contain typed expression nodes, never executable Python. FieldLayout adds storage=input/output/working, record_name and declaration span to PIC/offset/width/scale/digits/initial. FileBinding exposes name/record_name/status_name/direction/path without guessing from a filename.

Node arguments are fixed by kind: literal(value,literal_type numeric|alpha), reference(name), binary/compare/boolean(op,left,right); move(value,target); add/subtract/multiply(value,target,rounded,has_size_error); divide(left,right,target,rounded,has_size_error); compute(expression,target,rounded,has_size_error); if(condition); perform(paragraph,until,max_iterations); open(file,mode); read(file); write(record); close(file); display(values); stop(). Arithmetic body is ON SIZE ERROR; if uses body/otherwise; read body is AT END. Named PERFORM has no inline body. Uppercase names and exact numeric strings are used throughout; no floats/eval.

Static semantic validation checks elementary references/types, two distinct working PIC X(2) statuses, file direction/state and balanced CLOSE on all analyzed paths, no recursion/fallthrough and explicit return outcomes. OPEN branches symbolically into status00 success with a cleanup obligation and non00 failure without one. Actual alpha VALUE/MOVE facts, equality/inequality refinements and AND/OR source conditions retain path-specific opened flags; writes and file operations invalidate or replace affected facts. Flag names have no special meaning. Guarded READ/WRITE/CLOSE must have a successful OPEN on every reachable path. READ splits success, AT END and other failure; failure invalidates the relevant input record and blocks another READ until reopening. Exact non00 compiler status values are not guessed. CLOSE discharges a source cleanup attempt and invalidates status; this does not prove physical close success. STOP/MAIN exit must have no remaining successful-OPEN obligation. Unsupported/unproved paths refuse. All syntactic source paths are parsed; semantic proof failures are named refusals, not skipped statements.

Pre-flow induction-write/step traversals share a cumulative100000-statement-visit budget across one parse, checked before recursive call expansion; finite-loop data-flow unfolding has its own cumulative100000-visit budget. Exhaustion of either refuses unbounded_perform with no partial IR. These analysis-resource limits prevent acyclic call-DAG expansion and multiplicative loop unfolding from becoming unbounded work even when individual loops have finite caps. They do not assert the source itself loops forever.

The same flow budget now also counts before each path copy, condition expansion and append; every path collection is capped at256 before append (file_contract refusal). The solver retains alternatives rather than requiring identical open sets at an IF join. Unknown numeric predicates are explored conservatively; they do not invent a dominating loop initialization. Alpha unknown exclusions survive only width-preserving moves. These explicit finite domains may refuse otherwise valid source. Source reasoning establishes neither actual file availability nor runtime status/semantic parity. Conditional flags, failed-open paths, overwritten flags/statuses, repeated READ and analysis-budget cases await actual runtime fixtures under normal mode.

PERFORM UNTIL and RETURN-CODE require the source-bound native ProgramManifest. Loop annotations alone do not pass: exact test/initialization/update spans resolve to actual statements; a monotone integer step must hold on every body path, initial value must dominate the call, and exit must be reached without induction overflow within the declared 1..64 cap. The static proof domain is exact literal integer initialization and ADD/SUBTRACT or unit-coefficient integer +/- COMPUTE updates (including acyclic performed paths and matching conditional updates). More complex/input-dependent progression, nested loops that change the same induction field, non-dominating initialization or unresolved effects refuse `unbounded_perform`. This is an explicit remaining proof limitation, not a claim to accept every provable COBOL loop. Unreachable source still receives syntax/name/type/loop checks. General manifest sidecar/field artifact authentication remains admission work; parsing does not certify it.

`cobolmap.mapping.build_map(program)` consumes this exact IR and constructs the shared BehaviorMap. Mapping resolves source pointers against the retained original bytes and produces deterministic field/paragraph/effect/control entries and H1–H8 warnings. Conservative warnings are not reachable-bug demonstrations. Only closed expressible source-derived claims are extracted; each remains untested until genuine later oracle evidence. Detailed mapping/shared-model reconciliation and deferred validation are recorded in the source handoff.

The graph expands each call into a separate return context: a direct PERFORM returns only to its own continuation, while UNTIL tests before entry and routes body return back to that test. Empty paragraphs/branches and handler paths retain matching continuations. This is a static graph, never a trace. Shared edge categories collapse detailed labels into perform/branch/sequence. Context expansion has a hard4096-edge construction budget, checked before each append; exceeding it raises MappingLimitRefusal(code=map_limit,span) and returns no partial BehaviorMap. The eight-paragraph/source-line bounds alone do not prevent exponential call-DAG expansion. This explicit graph-materialization limit can refuse a parsed valid subset program; compact arbitrary-size call-graph representation is not implemented. Field record_name/storage/sign metadata uses the actual shared model, including internal embedded/packed hypotheses.

Static construction checks use stdlib AST parsing, source/diff inspection and a fresh implementation-lineage reviewer. Deferred: parser/refusal/IR fixtures, provider joins, compiler acceptance, PIC/packed/sign/rounding/status/intermediate probes, manifest proof/path cases, byte-span/hash vectors, map/hazard/claim behavior, CLI/translation integration and all runtime/admission checks. No candidate module was imported, no product function/test/build ran, and no dependency was installed during construction.
